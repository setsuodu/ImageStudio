就绪 · 对应你常用的 ffmpeg 命令
对应常用命令：
· 转 MP4：ffmpeg -i in.flv -c copy out.mp4（失败则自动重编码 libx264+aac）
· 裁剪：ffmpeg -ss 00:00:46 -i in.mp4 -to 00:02:00 -c copy out.mp4
· 改码率：ffmpeg -i in.mp4 -b:v 3000k -c:v libx264 -c:a copy out.mp4
· 抽帧：ffmpeg -i in.mp4 -r 24 frame_%03d.png
· 水平左半：ffmpeg -i in.mp4 -vf "crop=iw/2:ih:0:0" left.mp4
· 改比例：ffmpeg -i in.mp4 -vf "scale=...pad=..." -c:v libx264 out.mp4（pad 黑边 / crop 裁切）
· 拼接：ffmpeg -f concat -safe 0 -i list.txt -c copy out.mp4（多段首尾相接）
